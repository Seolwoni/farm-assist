# Farm Assist

Minecraft 26.2 (Fabric) 자동 농사 모드 — Made by seolwoni

- 괭이를 들고 밭의 두 모서리를 Shift + 우클릭해서 밭 지정 (여러 개 가능, 설정에서 목록 관리)
- 다 자란 작물만 수확하고 바로 다시 심기: 밀, 당근, 감자, 비트, 네더 사마귀, 사탕수수, 대나무, 호박, 수박, 코코아, 선인장, 달콤한 열매
- 한 바퀴 돌고 보관 → 5분 대기 → 반복
- 상자 여러 개(최대 10개, K로 지정) 분류 보관, 씨앗은 종류별 64개 남기고 모자라면 상자에서 가져오기
- 사람 같은 딜레이와 시선, 자동 밥, 몹·체력 안전장치, 상태·수확 통계 HUD
